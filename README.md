# TCP Client/Server Command Tool

A Python-based client/server networking project built in a controlled lab environment to explore TCP communication, command handling, modular design, and file integrity verification.

## Overview

This project was developed as part of cybersecurity coursework using Python and Kali Linux in VMware. It began as a basic client/server implementation and was later expanded into a more modular design with shared helper functions and SHA-256 file integrity verification.

## Features

- TCP socket communication
- Command execution
- Working directory navigation
- Privilege checking
- Screenshot capture and transfer
- File transfer support
- SHA-256 hash verification
- Modular shared utilities through `common.py`

## Technologies Used

- Python
- Kali Linux
- VMware
- Git
- GitHub

## Files

- `client.py` — handles client-side communication and command execution
- `server.py` — listens for connections and sends commands
- `common.py` — contains shared logic for file transfer and hashing

## Key Takeaways

This project helped strengthen my understanding of:

- TCP/IP communication
- Client/server workflows
- Refactoring code into reusable modules
- File transfer reliability
- Integrity verification using hashing
- Version control with Git and GitHub

## Disclaimer

This project was built and tested only in a controlled educational lab environment.
